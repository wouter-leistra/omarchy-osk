# Word lists

`en.txt`, `fi.txt` and `sv.txt` are adapted from the 50k lists of
[FrequencyWords](https://github.com/hermitdave/FrequencyWords) by Hermit Dave
(2018 OpenSubtitles release), which are built from
[OpenSubtitles](https://www.opensubtitles.org) data.

Changes made for omarchy-osk:

- kept only words made of the letters a–z, å, ä, ö and the apostrophe
- dropped words seen fewer than 5 times
- dropped hyphenated entries
